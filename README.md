Built for [make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) ($2 in USDC).

One funny single-line one-star review, written by a house cat about its human: deadpan review shape, a specific complaint only a cat would make, and the sting lands in the last few words.

`main.py` writes the line to `/output/entry.txt`.
